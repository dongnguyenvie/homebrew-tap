# homebrew-tap

Homebrew tap for BashCut and BashCutPro.

| App | Install | Notes |
|---|---|---|
| [BashCut](https://github.com/dongnguyenvie/BashCut) | `brew install --cask dongnguyenvie/tap/bashcut` | macOS 14 (Sonoma) or later |
| [BashCutPro](https://github.com/dongnguyenvie/BashCutPro) | `brew install --cask dongnguyenvie/tap/bashcutpro` | Apple Silicon, macOS 11 or later; also links `bashcutpro-cli` and `bcpro` |
